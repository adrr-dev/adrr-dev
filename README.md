### ♟️ About Me

```yaml
identity: Art Darrell Ridel Rumagit
focus: Backend & Systems Engineering, Concurrent Architecture, Relational Databases
philosophy: "Every move calculated: low-latency pipelines, rock-solid consistency, zero bloat."
```

Saya adalah mahasiswa Informatika (angkatan 2026) di **Universitas Udayana** yang berfokus mendalam pada rekayasa backend, perancangan sistem berperforma tinggi, dan pemodelan basis data yang tangguh. Saya memperlakukan arsitektur sistem selayaknya papan catur: terstruktur, penuh perhitungan, efisien tanpa instruksi sia-sia, dan siap menghadapi konkurensi skala tinggi.

- ⚙️ **Core Focus:** Merancang RESTful / gRPC API berkecepatan tinggi dengan Go, sistem terdistribusi, dan manajemen state deterministik.
- 🗄️ **Database & Performance:** Optimasi query, perancangan relasional kompleks (PostgreSQL, SQLite), migrasi aman, caching, dan transaksi ACID.
- ♟️ **Analytical Thinking:** Menggabungkan logika analisis strategi catur ke dalam mitigasi edge-case rekayasa perangkat lunak.
